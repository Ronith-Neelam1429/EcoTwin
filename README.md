# EcoTwin

EcoTwin is an interactive environmental digital twin for testing neighborhood-scale interventions before they are built.

This repository is currently set up as a React + TypeScript + Vite project shell. The app implementation has not started yet.

## Getting Started

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

## Environment

Copy `.env.example` to `.env` and add a Mapbox token when map features are implemented.
